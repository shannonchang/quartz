## 摘要（Summary）

Agentic AI 指能執行多步驟複雜任務（multi-step reasoning）的 AI 系統，有別於早期單輪問答的 LLM 應用。自 2025 年起，Agentic AI 從實驗室走向真實生產環境，Claude 滲透率成長最強（+340%，遠超 GPT-4o 的 +190%），企業 AI 預算中 Agent 相關基礎建設佔比達 68%（2026 Q1）。Agentic 任務的推論計算需求遠高於傳統問答，成為 [[AI半導體供應鏈]] 第二波結構性上升週期的核心驅動力，並是 [[AI生產力循環]] 的需求端引擎。

## 核心邏輯鏈

```
Agentic AI 落地
→ 推論運算需求指數級增長
→ GPU/NPU 採購週期拉長
→ CoWoS 先進封裝、HBM 記憶體、高速網路 IC 需求同步爆發
→ 半導體供應鏈迎來「第二波結構性上升週期」
（有別於 2023–24 年建置期的一次性採購潮）
```

## 關鍵數據（2025–2026）

| 指標 | 數值 |
|------|------|
| Claude 滲透率成長（2024 = 100） | +340% |
| GPT-4o 滲透率成長 | +190% |
| Gemini 滲透率成長 | +140% |
| Agentic 任務佔比年增幅度 | 2.4× |
| 企業 AI 預算中 Agent 基礎建設佔比 | 68%（2026 Q1） |

## 與傳統 LLM 的差異

- **傳統 LLM**：單輪對話、短上下文、推論計算量有限
- **Agentic AI**：多步驟任務鏈、長上下文、迴圈推論、工具呼叫；每完成一個任務消耗的算力可能是傳統的 10–100×

## 產業影響

- **推論 > 訓練**：2025 H1 開始，AI 算力需求結構從「訓練主導」轉為「推論主導」
- **硬體需求改變**：Agentic 推論偏好低延遲、高記憶體頻寬，驅動 HBM3e 與 CoWoS 需求
- **企業部署模式**：從 PoC 試點轉為大規模生產部署，帶動長期算力採購合約
