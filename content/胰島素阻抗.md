## 摘要（Summary）

糖只是燃料，**胰島素才是指揮**。血糖會不會出事，根本上是胰島素失控的問題。胰島素阻抗不只是「血糖偏高」的前期，而是一台自我加速的飛輪：阻抗讓胰臟代償更多胰島素，更多胰島素加重阻抗——這個正回饋系統在確診前 5 年已靜默運轉，而且瘦的人同樣可能身在其中（TOFI）。飛輪的最終站不在肝臟，不在血管，**在大腦**。

> HbA1c、空腹血糖是後期警報；空腹胰島素 + HOMA-IR 才是早期警報。

## 一、胰島素的角色

胰島素是身體的能量總指揮——不只降血糖，同時調度脂肪與蛋白質的儲存與釋放。

**胰島素在 → 儲存模式全開、動用模式全關**  
**胰島素不在 → 反過來**

演化意義：胰島素訊號家族可追溯至 7 億年前。1993 年 Kenyon 實驗：降低線蟲胰島素受體活性 → **壽命翻倍**（Nature）。胰島素不只管血糖，它管「成長/維持」「儲存/動用」「老/活」等核心決策。

## 二、高胰島素本身就有害（即使血糖正常）

| 傷害 | 機制 | 證據強度 |
|------|------|---------|
| 脂肪肝、高三酸甘油酯、低 HDL | 胰島素驅動肝臟 de novo lipogenesis | **共識，硬證據** |
| 高血壓 | 胰島素促腎小管留鈉 → 血容量增加 | 中等到強 |
| 某些癌症風險 | 胰島素激活 IGF-1 軸，推動細胞分裂 | 中等 |
| PCOS、痤瘡 | 刺激卵巢/皮脂腺分泌雄性激素 | **共識** |
| 代謝症候群 | 腹部肥胖＋高血糖＋高血壓＋高三酸甘油酯共同上游 | **共識** |

**標準體檢的盲點**：HbA1c、空腹血糖只告訴你「血糖壓住了」，沒告訴你「花了多少胰島素」。需另加驗**空腹胰島素**計算 HOMA-IR 才能看見早期阻抗。

**HOMA-IR 解讀**（= 空腹血糖 × 空腹胰島素 ÷ 405）：
< 1.0 理想 → 1–2 可接受 → 2–2.5 邊緣 → > 2.5 明顯阻抗 → > 3.5 嚴重阻抗

## 三、兩條獨立致病路徑（均有人體實驗支持）

**路徑一（Corkey）：高胰島素自己造成阻抗**  
長期高胰島素 → 細胞主動下調受體（保護性減敏）→ 阻抗  
*人體實驗：72–96 小時胰島素輸注，4 天內葡萄糖處理能力下降 20–40%*

**路徑二（Shulman）：異位脂肪塞住訊號鏈**  
過食/不動 → 肝臟脂肪堆積 → DAG/ceramide 物理性塞住訊號鏈 → 阻抗  
*人體實驗：脂肪輸注數小時內肌肉 DAG 上升 → 胰島素訊號斷掉*

兩條路徑共用「胰島素飆高」這個齒輪，在真實人身上同時發生、互相放大。

## 四、三器官連動的失靈瀑布

```
【肌肉】糖水庫失靈 → 餐後糖收不下（先出現餐後血糖偏高）
    ↓ 收不掉的糖轉送肝臟
【肝臟】選擇性阻抗：
    - 放糖煞車失靈 → 繼續自製糖 → 空腹血糖升高
    - 但做脂肪命令仍聽從 → 繼續 DNL → 脂肪肝
    ↓ 脂肪部分漏回血液
【脂肪組織】鎖油命令失靈 → 脂肪酸漏進血液 → 流回肝肌加重異位脂肪
    ↻ 循環放大
```

**肌肉的特殊地位**：正常狀態下吸收餐後 70–80% 葡萄糖。肌肉量低 = 糖水庫小 = 更多糖被導向肝臟 = 飛輪加速。這是[[蛋白質與肌肉老化]]節點中「阻力訓練是開關」的代謝底層原因。

## 五、自我加速的飛輪

```
過食/高糖/不動
    ↓
胰島素持續偏高
    ↓                    ↓
路徑一：受體下調      路徑二：異位脂肪 → DAG/ceramide
    ↓                    ↓
         → 阻抗加重 ←
                ↓
         胰臟代償更多胰島素
                ↻ 兩條路徑同時被推動
```

**飛輪的四個特性**：
- **自我加速**：正回饋，傷害是乘法的
- **長期隱形**：Whitehall II 研究：胰島素敏感度在確診前 **5 年**就開始陡降，空腹血糖要到確診前 3 年才明顯
- **越晚越難救**：早期阻抗 β 細胞能代償，晚期 β 細胞衰竭後不可逆
- **瘦不保證安全**：皮下脂肪緩衝容量因人而異

## 六、TOFI——外瘦內胖（東亞特別需要注意）

TOFI（Thin Outside, Fat Inside）：BMI 正常但皮下脂肪緩衝區小，脂肪溢進肝臟和內臟。

**東亞人特別容易 TOFI 的原因**：皮下脂肪增生上限先天偏低，較低 BMI 就開始溢進內臟。WHO 亞洲切點：過重 = BMI 23（非 25），肥胖 = 27.5（非 30）。

**女性特別節點**：停經後雌激素下降 → 脂肪分佈從下半身轉向腹部 → TOFI 保護消失。

**診斷工具**：標準體檢無法偵測 TOFI，需 DEXA（內臟脂肪量）+ ATI 超音波（肝臟脂肪）+ HOMA-IR + CGM。

## 七、阿茲海默是大腦版糖尿病（第三型糖尿病）

大腦也有胰島素受體。長期高胰島素血症讓 **IDE（胰島素降解酵素）** 被佔用，無暇清除 β-amyloid → 斑塊堆積 → 阿茲海默。

**流行病學**：第二型糖尿病患者阿茲海默風險增加 50–60%；胰島素阻抗（未達糖尿病）約增加 50%。

> 阿茲海默不是老化的必然，是代謝的必然。飛輪的最終站在大腦。
